Build and Emulator Workflow internal

Assemble, package, and launch a cassette-loaded MC6803 binary.

Build stages

  1. CRASM assembles `src/main.s` as an MC6803 Intel HEX image.
  2. `scripts/make_c10.py` wraps the binary in MC-10 name, data, checksum, leader, EOF, and CUE records.
  3. PowerShell invokes XRoar under WSL with the `mc10` machine and `mcx128` cartridge profile.

Commands

.space-invaders.ps1 build
.space-invaders.ps1 run
.space-invaders.ps1 check
.space-invaders.ps1 clean

The generated cassette is loaded with XRoar's `-run` path. Because MC-10 cassette hardware has no remote motor control, the emulator may require the tape-play control when running interactively.

See the repository README and platform baseline for address and loader details.
