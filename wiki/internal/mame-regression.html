Internal · MAME

MAME Regression Path internal

Independent emulator setup for cassette loading, timer execution, and MCX-128 configuration.

Why MAME was upgraded

The installed MAME 0.220 driver did not expose an MCX-128 slot and rejected the project's .c10 cassette image. MAME 0.289 exposes the MC-10 mcx128 cartridge slot, accepts .c10, and exposes 4K, 8K, 20K, and 32K RAM selections. The current MAME source contains the MC-10 driver and MCX-128 device implementation.

Use the official MAME releases page for the current binary. The local test binary used for this run was E:\tools\mame0289-bin\mame.exe.

ROM and cartridge setup

mame.exe -listroms mc10 -rompath E:\path\to\roms
mame.exe -verifyroms mc10 -rompath E:\path\to\roms
mame.exe mc10 -ext mcx128 -rompath E:\path\to\roms

Place the MCX-128 firmware in a set directory recognized by MAME, for example roms\mcx128\mcx128bas.rom, or use a verified software-list ZIP. The project MCX image matches MAME's mcx128bas.rom checksum. The option is -ext mcx128; -slot ext=mcx128 is not valid for this driver.

Automated timing-test path

mame.exe mc10 -noreadconfig -ramsize 20K `
  -rompath "E:\path\to\ladybug\roms;E:\path\to\mame\roms" `
  -cass "E:\path\to\build\timing-calibrator.c10" `
  -autoboot_delay 2 `
  -autoboot_script "E:\path\to\scripts\mame-cassette-autoplay.lua" `
  -seconds_to_run 70 `
  -snapshot_directory "E:\path\to\build\mame-snapshots"

The script sequence is: post CLOADM{ENTER}, wait until the BASIC loader is ready, start cassette playback, post EXEC{ENTER} after the transfer interval, then call the MC-10 screen snapshot API. The snapshot is the regression artifact; process state alone is insufficient.

Expected evidence

  • The output log contains MC-10 keyboard: CLOADM{ENTER}, MC-10 cassette: PLAY, and MC-10 keyboard: EXEC{ENTER}.
  • The snapshot shows the timing calibrator rather than only the loaded file name and OK.
  • The program reaches TIMER: OK and the event counter advances.
  • A bare-MC-10 run may report MCX128 ERROR; that is expected without the MCX bank registers.

The first corrected MAME run demonstrated that cassette transfer could reach the file-name and OK state. A subsequent run must include EXEC before interpreting the screen as a timer failure.

Current status: the helper logs both CLOADM{ENTER} and EXEC{ENTER}, but the captured MAME screen still shows the cassette file name and OK instead of the calibrator. Treat the MAME EXEC handoff as an open investigation until a captured TIMER: OK result is obtained.

RAM-model boundary

MAME's -ramsize 8K is useful for approximating the piggybacked internal 8 KiB modification because the MC6847 sees the same flat RAM device in the driver. It is not proof that physical expansion RAM is on the VDG bus. Use the MCX cartridge configuration separately for eight banked 16 KiB external CPU windows.

Source-level mapping is recorded in docs/mcx128-register-map.md and docs/mc10-platform.md.
