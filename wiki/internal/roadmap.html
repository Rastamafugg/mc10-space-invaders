Roadmap internal

Dependency order for the new MC-10 game.

  1. Bootstrap: build and cassette-load the MC6803 smoke test with MCX-128.
  2. Platform: reconcile schematics, service-manual behavior, XRoar behavior, and physical test results.
  3. Rendering: select text, semigraphics, or custom character techniques and build a repeatable screen test.
  4. Input and timing: document keyboard matrix reads and measure the usable MC6803 frame budget.
  5. Game loop: implement player, invaders, projectile, collision, score, lives, and level state.
  6. Expansion: move data and optional runtime services into explicit MCX-128 banks.
  7. Distribution: retain `.bin` and `.c10` artifacts and validate XRoar, real cassette/audio, and physical MC-10 paths.

Do not start game-level optimization before the platform and timing baselines are measured.

Initial scope is the bootstrap milestone only.
